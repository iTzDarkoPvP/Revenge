## 🛠️ Herramientas

## 📦 Instalación

```bash
git clone https://github.com/iTzDarkoPvP/RevengeKIT.git
cd RevengeKIT
chmod +x install.sh && ./install.sh
```

El instalador detecta tu SO automáticamente e instala todo lo necesario.

---

## 🚀 Uso

```bash
python3 main.py
```

Selecciona el número de la herramienta y sigue las instrucciones en pantalla.
